# Gestão na Ponta

(verde)

Barra de Navegação Inferior Fixa (Bottom Bar branca):

4 abas com ícones e rótulos: Início (ativo em Azul Petróleo), Caixa, Serviços e Raio-X, com um botão circular flutuante grande (+) em Verde Esmeralda no centro.

Interatividade do botão +: Ao clicar no +, abrir um menu deslizante de baixo para cima (Bottom Sheet) com 3 botões grandes e claros: "Registrar Entrada" (verde), "Registrar Saída" (vermelho) e "Minha Retirada" (azul petróleo).
